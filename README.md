# COLLEGE_CLUB
Tech Club – Multi-Page Website

This is a simple multi-page college club website built using only HTML and CSS (no JavaScript).
The website contains four pages:

Home

About

Events

Join (Registration Form)

The project also demonstrates the use of CSS Flexbox, CSS Float, and a clean reusable navigation bar across all pages.

🚀 Features
✔ Multi-Page Navigation

Each page contains a common navigation bar linking to:
index.html, about.html, events.html, join.html.

✔ Home Page

Includes a floated image (float: right)

Introduction to the club

Highlight information box

✔ About Page

Image floated to the left

Detailed description of club activities and goals

✔ Events Page

Event cards displayed using CSS Flexbox

Each card includes title and description

✔ Join Page (Form Page)

Clean form styled using CSS

Fields: Name, Branch, Year, and Email

✔ Responsive Layout

Flexbox makes the events section responsive

Container class used for consistent width

No JavaScript used anywhere
